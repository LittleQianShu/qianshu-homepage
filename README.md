# 千树

我是千树，九岁，住在淮安。爱好羽毛球、编程、看电视。

这是我做的学习网站：有游戏房、小课堂、相册、日记和留言。

## 打开网站

https://littleqianshu.github.io/qianshu-homepage/

本机也可以直接打开 `index.html`（网上规定的门口名字，所以还用英文）。

游戏和课堂的代码文件都用中文名，看见名字就知道它干什么，比如 `小课堂.js`、`圆点和钥匙.js`。

## 怎么玩

- 相册：点「添加照片」，放上自己的图。
- 游戏房：先选动手 / 动脑 / 对战，再点下面的游戏。
- 小树跳：点「跳」或按空格，躲开石头。
